# Dvir Chakim

Electrical engineer (B.Sc.) working where hardware, embedded software and ML meet. Field Applications Engineer at Nisko Projects. Based in Israel.

I take models from a PyTorch prototype to running quantized on an edge NPU, and I measure them against the classical baseline they are meant to replace. Lately I apply neural networks to RF and DSP problems that used to be classical-only: demodulation, preamble synchronization and anti-jam array processing.

## Focus

- **Edge AI and NPU acceleration:** DEEPX, Axelera Metis, Hailo, EdgeCortix, Mobilint. ONNX graph surgery, INT8 calibration, compilation and on-device validation.
- **AI for RF and signal processing:** SDR, beamforming and array processing, digital communications.
- **Embedded systems and IoT:** STM32, Infineon PSoC 6, ESP32, Raspberry Pi, Jetson, Yocto. LoRaWAN with ChirpStack, MQTT, Node-RED, InfluxDB and Grafana.

## Selected projects

- [Deepx-yolo11-balls-model](https://github.com/dvirchakim/Deepx-yolo11-balls-model): YOLO11 compiled for the DEEPX M1 NPU, real-time ball detection.
- [GrinnGenio700-AxeleraMetis](https://github.com/dvirchakim/GrinnGenio700-AxeleraMetis): working Axelera Metis driver and install package for the Grinn Genio700 SBC.
- [LoRa-AirQuality](https://github.com/dvirchakim/LoRa-AirQuality): low-power LoRaWAN air-quality node with deep sleep and session persistence.
